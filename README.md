# 바로채점

종이 문제지를 푼 뒤 답만 입력하면 문항별 O/X만 보여주는 채점 웹앱입니다.

## 사용 흐름

1. 출제자가 날짜, 문제 수, 객관식/단답형 정답을 등록합니다.
2. 생성된 전용 링크를 풀이자에게 보냅니다.
3. 풀이자가 답을 제출합니다.
4. 사이트는 정답이나 풀이 없이 문항별 O/X만 표시합니다.
5. 틀린 문제는 다시 답을 입력해 고칠 수 있습니다.
6. 출제자는 별도의 관리자 링크에서 문제 번호별 답 변경 기록을 확인합니다.

정답은 서버에서 해시로 비교하며 친구 화면이나 API 응답에 포함하지 않습니다. 관리자 링크는 임의로 추측하기 어려운 별도 비밀 토큰으로 보호됩니다.
